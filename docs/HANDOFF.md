Daily completion means planned work was performed, not mastery. All accepted FSRS ratings count; a finite Review block can complete while the existing Review session remains active. A corrective task needs one accepted saved answer, even incorrect. Lesson work needs normal owned progress for the planned version to reach the target position. Event baselines exclude earlier/tied existing evidence; immutable source rows deduplicate replay. Daily writes only its own derived progress, never source grading/scheduling/history. Explicitly unavailable tasks resolve without performed-work credit or blocking the remaining plan. Terminal plans and skipped targets never reopen.
